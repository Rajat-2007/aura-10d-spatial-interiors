## 🌟 Key Highlights & Features

### 1. Real-Time 3D WebGL Room (Three.js)
- **Mouse-driven 3D Parallax & Orbit**: Camera coordinates glide smoothly (`lerp` physics) as you move your mouse.
- **Floating 3D Hotspots**: Clickable holographic pins positioned in 3D space. Clicking a pin glides the camera directly to that furniture piece and displays a cyber-glass inspection card.
- **Circadian Lighting Mode Engine**: Live switcher for **Day (Sunlight)**, **Sunset (Golden Hour)**, **Midnight (Cozy Warmth)**, and **Cyber (Cyan Neon)** that updates Three.js directional, ambient, and point lights in real-time.

### 2. 360° Interactive Panoramic Room Explorer
- Drag left and right with mouse to rotate full 360-degree high-definition room views.
- Zoom in and out controls for inspecting architectural details.

### 3. Horizontal Mouse-Scroll Room Matrix (Left-to-Right Carousel)
- Grab and drag with mouse left/right.
- Mouse wheel horizontal scrolling synchronization.
- Tactile hover cards with 3D tilt effects (`perspective(1000px)`).

### 4. 10D Procedural Spatial Audio Synthesizer (Zero External Audio Files)
- Built completely using browser **Web Audio API**.
- 4 luxury spatial soundscapes:
  - 🪐 **Penthouse Ambient Drone** (Harmonic luxury drone)
  - 🌧️ **Rain on Double Glazing** (Pink noise filter)
  - 🔥 **Travertine Hearth Fire** (Low-frequency warmth)
  - 🌬️ **High-Rise Sky Breeze** (Bandpass spatial air sweep)
- 360-degree orbital binaural panner that circles around your ears.
- Real-time frequency spectrum visualizer rendered to canvas.

## 🚀 How to Run in VS Code

1. **Extract the ZIP file** (`aura-10d-spatial-interiors.zip`).
2. Open the unzipped folder in **VS Code**:
   ```bash
   code aura-10d-spatial-interiors
   ```
3. **Launch the site**:
   - **Option A (Recommended)**: Right-click `index.html` and click **"Open with Live Server"**.
   - **Option B**: Double-click `index.html` to open directly in any modern browser (Chrome, Edge, Brave, Safari, Firefox).

*No `npm install` or build step required. Zero dependencies breakages. 100% self-contained!*
